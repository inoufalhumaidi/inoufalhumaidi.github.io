# Inouf Alhumaidi — Analyst Portfolio

Personal portfolio site, built with plain HTML/CSS/JS and hosted on GitHub Pages.

Live at: https://inoufalhumaidi.github.io

## Structure

- `index.html` — page content and structure
- `styles.css` — theme tokens, layout, light/dark mode
- `script.js` — theme toggle, mobile menu, scroll reveal, stat counters

## Editing

All content (bio, skills, projects, experience, contact links) lives directly in `index.html` — search for the
section you want to change (`#about`, `#skills`, `#projects`, `#experience`, `#contact`) and edit the text/links
in place. No build step is required; just edit and push.

## Deploying

Pushing to `main` triggers GitHub Pages to redeploy automatically (configured under repo Settings → Pages,
source: `main` branch, `/ (root)`).
